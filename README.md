# Graph Crossings Prediction

A machine learning project for predicting graph crossings.

## Overview
This repository explores methods for predicting edge crossings in graph layouts using graph algorithms and machine learning.

## Features
- Data preprocessing
- Feature engineering
- Model training
- Evaluation

## Installation
```bash
git clone https://github.com/Prime47x/graph-crossings-prediction.git
cd graph-crossings-prediction
pip install -r requirements.txt
```

## Usage
Run the training scripts in `src/` after preparing the dataset.
